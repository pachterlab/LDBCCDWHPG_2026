# LDBCCDWHPG_2026

This repository is an alias for **[pachterlab/Goentoro](https://github.com/pachterlab/Goentoro)**, which contains the code and analysis for:

Yutian Li, Jesus del Rio Salgado, Gloria Bates, Zevin J. Condiotte, Maya Caskey, Christian M. Dimayuga, Brian Williams, Ingileif Hallgrimsdottir, Lior Pachter, and Lea Goentoro. **[Early injury responses to nutrient treatment in adult Drosophila limb](https://doi.org/10.1242/bio.062737)**. *Biology Open* 15(10), bio062737 (2026).

**[Go to the code and documentation →](https://github.com/pachterlab/Goentoro)**

The alias follows the Pachter Lab convention of author last-name initials in order followed by the publication year. The original Goentoro repository remains the source of the code and retains the URL linked from the paper.
